## Design

The site uses an original static layout written in plain HTML, CSS, and
JavaScript with no external assets or build step. Its structure follows common
conventions of Linux distribution homepages, while using no code or assets
from those websites.

The display face is **Instrument Serif** (`assets/fonts/InstrumentSerif-latin.woff2`,
`assets/fonts/InstrumentSerifItalic-latin.woff2`), body text is **Inter**
(`assets/fonts/Inter-var-latin.woff2`), and labels are set in **JetBrains Mono**
(`assets/fonts/JetBrainsMono-var-latin.woff2`). All are copyright their
respective project authors and are distributed under the SIL Open Font License
1.1 ([Instrument Serif](assets/fonts/OFL-InstrumentSerif.txt),
[Inter](assets/fonts/OFL-Inter.txt),
[JetBrains Mono](assets/fonts/OFL-JetBrainsMono.txt)).
